# Streamer Toolkit | أدوات الستريمر

**Live site / الموقع:** https://aisha070.github.io/StreamerToolkit/

Free browser tools for streamers. Everything runs on your device, and your images are never uploaded anywhere.

## What's inside

- **Panels**: make Twitch "About" panels. Drag text anywhere, add as many texts as you want, pick a font, size and color, and put an image or GIF behind the text. Download as PNG, or as GIF when the background is animated.
- **Emote & Badge Resizer**: upload one image or GIF and get every Twitch size (emotes 112/56/28, badges 72/36/18). Keeps transparency and GIF animation, and warns you if a file is too big.
- **Background Remover**: turns a plain-color background transparent (PNG, JPG, WebP and animated GIF), with an erase/restore brush for cleanup. Send the result straight to the resizer.
- **English / العربية**: switch the whole interface with one button.

## Tips

- Click a panel, then use the **arrow keys** to move the selected text (hold **Shift** to move faster).
- In the text box, **Enter** makes a new line and **Alt + arrow keys** moves the text while you type.
- The background remover works best with solid colors (green screen, white, black). It is not an AI cut-out.

## Use it

Open the live site above. No sign-up, nothing to install.

## Publish your own copy (GitHub Pages)

1. Upload `index.html` and `config.js` to a public GitHub repository (the file must be named exactly `index.html`).
2. Go to **Settings → Pages**, choose **Deploy from a branch → main → / (root)**, then Save.
3. Your site will be at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Support button

Edit `config.js` to change the support link, change its text, move it, or hide it (`enabled: false`).

## بالعربي

أدوات مجانية للستريمرز تعمل كلها داخل متصفحك، وصورك لا تُرفع إلى أي مكان.

- **البانلات**: صمّم بانلات Twitch، واسحب النصوص وأضف منها بقدر ما تريد، واختر الخط والحجم واللون، وضع صورة أو GIF خلف النص.
- **تغيير حجم الإيموت والبادج**: ارفع صورة أو GIF وتحصل على كل مقاسات Twitch جاهزة، مع الحفاظ على الشفافية والحركة.
- **إزالة الخلفية**: تجعل الخلفية ذات اللون الواحد شفافة، ومعها فرشاة للتنظيف، وتقدر ترسل النتيجة مباشرة لأداة تغيير الحجم.
- **عربي / English**: زر واحد يبدّل لغة الواجهة كاملة.

**نصائح:**

- اضغط على البانل ثم استخدم **الأسهم** لتحريك النص المحدد (مع **Shift** أسرع).
- داخل خانة الكلمات: **Enter** يعمل سطر جديد، و**Alt + الأسهم** تحرك النص وأنت تكتب.
- إزالة الخلفية تعمل أفضل مع الألوان الثابتة (شاشة خضراء أو أبيض أو أسود)، وهي ليست قصاً بالذكاء الاصطناعي.

**للنشر:** ارفع `index.html` و`config.js` إلى مستودع عام في GitHub، ثم من **Settings ← Pages** اختر الفرع **main** والمجلد **/ (root)**.
